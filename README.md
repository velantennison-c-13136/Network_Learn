# Network Learn Atlas

This is a static learning website for networking, protocols, server infrastructure, and database fundamentals.

## Publish publicly with GitHub Pages

1. Create an empty GitHub repository.
2. Push this folder to the repository on the `main` branch.
3. In the GitHub repository settings, open `Pages` and set the source to `GitHub Actions`.
4. Push to `main` again if needed. The workflow in `.github/workflows/deploy-pages.yml` will publish the site.

Once deployed, the site will be available at:

`https://<your-github-username>.github.io/<your-repository-name>/`
